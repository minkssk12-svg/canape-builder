# 나만의 카나페 만들기

초등 실과 '건강 간식 만들기' 수업용 웹앱입니다. 크래커 위에 토핑을 올려 카나페를 디자인하고, 5가지 식품군과 필요한 개수를 점검한 뒤 완성 카드를 이미지로 저장합니다. '카나페 가게 게임' 탭에서는 주방 재료 통에서 크래커·소스·토핑을 도마로 끌어다 놓아 손님 주문(재료, 식품군, 알레르기 조건)을 제한 시간 안에 맞추는 6단계 미니게임과 무한 모드를 할 수 있고, 번 코인으로 상점에서 도구와 꾸미기를 살 수 있습니다. 코인과 산 물건은 학생 기기의 브라우저에만 저장됩니다.

- 파일 하나(index.html)로 동작하며 서버, API 키, 로그인이 필요 없습니다.
- 학생이 만든 내용은 어디에도 저장되거나 전송되지 않습니다.
